# Basic Sample

`Demo.unity`を開いてPlayしてください。

- `WASD`: ポイを水平移動
- `Q / E`: ポイを下降／上昇
- `Shift`: 高速移動
- `Z / X`: 水中回転
- `C`: TestCubeを再投下
- `R`: Paper、Wetness、CubeをReset

このSampleのControllerと入力処理はSample専用で、Runtime Package本体には含まれません。

Input Systemのみ、旧Input Managerのみ、Active Input HandlingがBothのプロジェクトで動作します。Input SystemをSampleのためだけに追加する必要はありません。

以前のPackage Versionから更新した場合、既にコピー済みのSampleは自動更新されません。古いVersionのSampleフォルダーを削除してから再Importしてください。
